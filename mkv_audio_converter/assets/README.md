# Application icon

The editable `icon.svg` is the unchanged KDE Breeze `audio-x-generic` icon
(64 px variant), from Fedora's `breeze-icon-theme-6.31.0` package.

Copyright © 2014 Uri Herrera and other KDE Breeze contributors.
License: **LGPL-3.0-or-later**, with the artwork clarification in
`LICENSES/Breeze-COPYING-ICONS.txt` in the project root.

Source: https://invent.kde.org/frameworks/breeze-icons

`icon.png` and the multi-resolution `icon.ico` are rendered from this SVG,
without visual changes. Regenerate with `QT_QPA_PLATFORM=offscreen python
tools/build_icons.py`. Their license and attribution are the same as the SVG's.
The source SVG and license accompany the source and binary distributions.
